ESP32-OS Web Flasher

Install ESP32-OS on your board directly from your browser.

Install

Check the name of your board, then select it above.

Your browser does not support Web Serial. Please use Chrome or Edge on a desktop computer. Web Serial needs a secure connection (https).
  1. Connect the board's USB TO UART port to your computer.
  2. Connect the board's USB port to your computer. Use the one that shows up as USB JTAG/serial debug unit.
  3. Click Connect and pick the serial port of the board.
  4. If the board is not detected: hold BOOT, press RESET, release BOOT, then try again.
  5. After flashing, press RESET. The first start opens the setup assistant (language, keyboard, Wi-Fi).

Choosing Erase device deletes everything on the internal flash, including saved settings, Wi-Fi networks and game saves. Without erasing, ESP32-OS, Doom and Quake are replaced and the data partition of an earlier ESP32-OS is kept. Other firmware on the board is overwritten.

Guition: updates over Wi-Fi are not available. Install new versions with this page.

What gets installed

  • Bootloader with automatic rollback, partition table
  • ESP32-OS (slot A), the Doom and Quake programs
  • No game data: Doom and Quake need the shareware files on the microSD card (see the README).

Manual flashing

With espflash and the files of the release:

espflash write-bin 0x2000 bootloader.bin
espflash write-bin 0x8000 partition-table.bin
espflash write-bin 0x10000 otadata-leer.bin
espflash write-bin 0x20000 esp32os.bin
espflash write-bin 0xC00000 doomapp.bin
espflash write-bin 0xE00000 quakeapp.bin

espflash write-bin 0x2000 guition-bootloader.bin
espflash write-bin 0x8000 guition-partition-table.bin
espflash write-bin 0x10000 guition-otadata-leer.bin
espflash write-bin 0x20000 guition-esp32os.bin
espflash write-bin 0x610000 guition-doomapp.bin
espflash write-bin 0x810000 guition-quakeapp.bin

Check the files against SHA256SUMSguition-SHA256SUMS from the release first.
